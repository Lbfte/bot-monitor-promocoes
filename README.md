# Monitor de Promoções e Alertas

Um sistema web completo para monitoramento automatizado de preços de e-commerce. O usuário insere o link de um produto das lojas suportadas, define uma meta de preço e seu e-mail. Quando o valor atinge ou fica abaixo do alvo estipulado, o sistema dispara uma notificação via e-mail.

---

# Importante:

A plataforma permite o monitoramento de múltiplos produtos de forma simultânea. Para a primeira versão (MVP), o sistema possui suporte focado nas plataformas Mercado Livre e Amazon, com arquitetura preparada para expansão de novas lojas em versões futuras..

## Funcionalidades

- **Monitoramento por URL:** Suporte a links do *Mercado Livre* e *Amazon*.
- **Captura Automática:** Identificação de título, imagem e preço atual no cadastro.
- **Varredura Periódica:** Checagem automatizada de preços em segundo plano.
- **Alertas por E-mail:** Notificação visual em HTML quando a meta de preço é atingida.
- **Controle Anti-Spam:** Módulo que limita disparos repetidos a um intervalo mínimo de 24 horas.
- **Histórico Visual:** Painel interativo com gráfico de variação de preços ao longo do tempo.
